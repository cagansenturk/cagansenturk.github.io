Verified live: the POST endpoints (/api/anla, /api/etki, /api/jargon) and the GET endpoints (/api/fonlar, /api/bugun, /api/nasdaq, /api/bist) all return 200 with real data. GET now works from the browser too — corsHeaders() advertises GET, POST, OPTIONS.

Note — how auth works here: every request sends a publishable key (pk_*) via the x-api-key header, read from the <script data-key> tag. pk_ keys are safe to expose in browser JS because the API pairs them with an Origin allowlist check — so a page only works when it is served from an allowed origin (see point 2). Opening this file directly as file:// sends no Origin, so the API replies 403 Origin başlığı eksik. For server-to-server use (no Origin, no browser) use a secret key (sk_*) instead.
